# Mercato

Одностраничный сайт для инвесторов: квартиры в сданном ЖК Mercato в Сочи (ул. Яна Фабрициуса, 2/23М) как доходный актив.

Перенос дизайн-макета (`Mercato-investors.html`) на Next.js. Макет адаптивный, страница собрана одним деревом компонентов. Стили макета перенесены инлайном, как в исходнике. В `globals.css` лежит то, что инлайном не сделать: шапка, кнопки и наведение, поля формы, анимации первого экрана.

## Стек

- Next.js 16 (App Router, standalone-сборка)
- React 19, TypeScript
- Docker

## Запуск

```bash
npm install
npm run dev          # http://localhost:3000
```

Прод:

```bash
npm run build
node .next/standalone/server.js
```

Docker:

```bash
cp .env.example .env
docker compose up --build
```

## Переменные окружения

Смотрите `.env.example`.

| Переменная | Когда читается | Назначение |
|---|---|---|
| `NEXT_PUBLIC_SITE_URL` | сборка | канонический адрес сайта: метаданные, микроразметка, `robots.txt`, `sitemap.xml` |
| `YANDEX_VERIFICATION` | сборка | код подтверждения прав в Яндекс.Вебмастере |
| `GOOGLE_SITE_VERIFICATION` | сборка | то же для Google Search Console |
| `NEXT_PUBLIC_YM_ID` | сборка | номер счётчика Яндекс.Метрики; пусто - счётчик не подключается |
| `TELEGRAM_BOT_TOKEN` | запуск | токен бота для доставки заявок; без него заявка только пишется в журнал |
| `TELEGRAM_CHAT_ID` | запуск | чат или группа, куда бот шлёт заявки |
| `TELEGRAM_THREAD_ID` | запуск | тема супергруппы-форума; пусто - бот пишет в общую ленту |
| `TRUST_PROXY` | запуск | `1`, только если перед приложением стоит доверенный прокси |
| `LEADS_DATA_DIR` | запуск | каталог с журналом заявок, в докере том `leads-data` |
| `WEB_PORT` | запуск | порт хоста в docker compose, по умолчанию 3000 |

Переменные с пометкой «сборка» Next подставляет в код при `npm run build`, поменять их на запущенном контейнере нельзя. В `docker-compose.yml` они уходят в `build.args`, так что смена домена, кода вебмастера или счётчика - это `docker compose up --build`.

**Домена пока нет.** Без `NEXT_PUBLIC_SITE_URL` канонический адрес, карта сайта и микроразметка указывают на `http://localhost:3000`. Перед выкладкой адрес нужно задать. Кириллический домен можно писать как есть: он приводится к punycode через `new URL().origin`.

## Превью на GitHub Pages

```bash
npm run pages
```

Скрипт `scripts/gh-pages.sh` собирает статическую версию во временной копии проекта и пушит её в ветку `gh-pages`. Адрес: `https://<владелец>.github.io/<репозиторий>/`. Рабочее дерево и `.next` не трогаются.

Отличия от прод-сборки:

- `output: 'export'` и `basePath` из имени репозитория (`STATIC_EXPORT=1`, `NEXT_PUBLIC_BASE_PATH`); пути к картинкам идут через `asset()` из `src/lib/asset.ts`;
- приёма заявок нет: на Pages нет сервера, форма покажет ошибку отправки;
- `SITE_NOINDEX=1`: `noindex, nofollow` в мета-тегах и `Disallow: /` в `robots.txt`, чтобы превью не попало в выдачу дублем будущего домена;
- счётчик Метрики и коды вебмастеров отключены.

В настройках репозитория (Settings → Pages) источник должен быть `Deploy from a branch`, ветка `gh-pages`, папка `/`. Для приватного репозитория Pages работает только на платном тарифе владельца.## Структура

## SEO

Тексты метаданных и сборка микроразметки лежат в `src/lib/seo.ts`. Адрес, телефон, фотографии и список удобств берутся из `src/lib/content.ts`, из тех же констант, что рисуют страницу.

Выдаётся:

- `title`, `description`, `canonical`, `keywords`;
- Open Graph и Twitter Card с превью 1200x630, снятым с первого экрана;
- `robots.txt`: `/api/` закрыт, `Sitemap:`, отдельный блок для Яндекса с `Clean-param` (utm-метки, `yclid`, `gclid` и другие, список в `CLEAN_PARAMS`), чтобы рекламные ссылки не плодили дубли главной;
- `sitemap.xml` со всеми фотографиями страницы, `lastmod` по дате сборки;
- микроразметка одним `@graph`: `WebSite`, `WebPage` и `ApartmentComplex` с адресом, телефоном отдела продаж, логотипом, фотографиями с подписями и списком удобств;
- логотип 1000x1000 на тёмном фоне (`public/logo.png`) в микроразметке и карте сайта;
- иконки и `manifest.webmanifest`; в `favicon.ico` только круг с буквой M, орнамент в 16-32px не читается;
- `max-image-preview:large` для Googlebot;
- мета-теги подтверждения прав, если заданы `YANDEX_VERIFICATION` и `GOOGLE_SITE_VERIFICATION`;
- редирект 301 с `www.` на основной домен;
- Яндекс.Метрика, если задан `NEXT_PUBLIC_YM_ID`. Цели: `lead` - заявка отправлена, `phone` - нажатие на телефон. Цели с такими идентификаторами нужно завести в интерфейсе Метрики (тип «JavaScript-событие»).

Разметка страницы: один `h1`, заголовки секций `h2`, карточки `h3`, характеристики списками `dl`, шаги списком `ol`. Все фотографии - `<img>` с описательным `alt`. Текст отдаётся в HTML с сервера, без JavaScript страница видна целиком.

Скорость: фото первого экрана грузится с `fetchpriority="high"`, остальное лениво. Изображения переведены в WebP: 6,8 МБ исходников стали 3 МБ (рендер обхода Адлера из PNG 3,2 МБ в 0,3 МБ). Шрифты Prata и Jost раздаются с того же домена через `next/font`.

## Анимации

Логика перенесена из скрипта макета, тайминги и кривые те же.

- Первый экран: фото отъезжает с масштаба 1.25, строки заголовка выезжают из-под маски, цифры поднимаются по очереди. В макете это запускалось скриптом; здесь сделано на CSS, чтобы анимация шла с первой отрисовки, а не после гидрации.
- Ниже: блоки поднимаются при прокрутке, фотографии открываются шторкой, цифры считаются от нуля. Скрываются только блоки ниже экрана на момент загрузки.
- Параллакс фотографий и полоса прогресса чтения считаются по событию прокрутки, не чаще кадра.
- При `prefers-reduced-motion` анимации отключены.

## Заявки

Форма одна, в конце страницы: имя, телефон, бюджет. Кнопки «Запросить наличие и цены» в планировках и «Получить точный расчёт» в калькуляторе ведут к ней и добавляют в заявку выбранную планировку или параметры расчёта.

Российский номер набирается по маске `+7 (___) ___-__-__` и должен быть полным; номер с другим кодом страны вводится без маски, 10-15 цифр. Скрытое поле-ловушка отсекает ботов.

Заявка дописывается в `LEADS_DATA_DIR/leads.jsonl` до попытки отправки в Telegram, недоставленные дублируются в `leads-undelivered.jsonl`. Ошибки доставки посетителю не показываются: заявка уже принята. В логе сервера они видны строкой `lead not delivered to telegram`.

Частота ограничена по номеру (3 в час), по источнику (10 в час, только при `TRUST_PROXY=1`) и глобально (120 в минуту).

### Telegram

1. У `@BotFather`: `/newbot`, токен в `TELEGRAM_BOT_TOKEN`.
2. Добавить бота в рабочую группу и написать там любое сообщение.
3. `npm run tg chats` - напечатает готовую строку `TELEGRAM_CHAT_ID=...`, для групп с темами ещё и `TELEGRAM_THREAD_ID=...`.
4. `npm run tg test` - в группу придёт пробная заявка.

## Отличия от макета

- Переключатели шрифтовых пар и акцентного цвета из редактора макета не перенесены, оставлены значения по умолчанию: Prata и Jost, `#B08D57`.
- Размытие под шапкой включается только после прокрутки. В макете оно было и над первым экраном, из-за чего по фото шла полоса с резкой границей.
- В блоке «Инфраструктура» плитка бассейна занимает две колонки только от 700px. В макете на телефоне это ломало сетку и давало горизонтальную прокрутку.
- Бегущая строка зациклена без скачка (в макете сдвиг был на полшага меньше периода).
- Мобильное меню и шапка переключаются через CSS, а не по ширине окна в скрипте: нет мигания до гидрации. При открытом меню страница под ним не прокручивается, меню закрывается по Escape.
- Форма заявки настоящая: проверка телефона, состояния отправки и ошибки.

Высота страницы на 1440px совпадает с макетом до пикселя (11242px), сверено скриншотами.
